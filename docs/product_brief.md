# FluffyGo 项目简介

## 一句话介绍

FluffyGo 是一个 AI 宠物友好本地生活消费路线助手，面向城市养宠用户在核心商圈中的短时带宠出行需求，把一句话输入转化为可执行、可调整、可连接交易的本地生活路线。

## 用户痛点

- 带宠出门不是单点搜索问题，而是路线组合问题：哪里能散步、哪里能坐下、哪里能补给、哪里风险低。
- 核心商圈人流密度高，养宠用户需要提前知道宠物压力、拥挤风险和室内携宠限制。
- 现有 POI 信息分散，用户需要在地图、点评、社交平台之间反复切换确认。

## 解决方案

FluffyGo 将用户的一句话需求解析成结构化条件，包括地点、可用时间、宠物类型、宠物体型、预算、偏好和避免项。系统基于 POI 数据和宠物友好规则，生成组合式路线：

- 短时活动空间
- 宠物友好消费点
- 宠物服务/补给点
- 雨天备选点

同时为每个 POI 展示宠物友好状态、可信度、风险提示和可执行交易动作。

在最新版本中，FluffyGo 进一步从“路线推荐”升级为“带宠出行决策助手”，新增：

- 出行可行性评分：判断当前是否适合出发。
- 风险雷达：展示人流、室内准入、犬型适配、天气、规则不确定性和宠物压力。
- 路线对比：同时比较主路线、低压力路线和雨天备选路线。
- C 端带宠互助社区：让用户反馈实时携宠体验。
- C 端代溜服务：当用户没时间亲自出门时，连接认证代溜服务。

## Demo 场景

南京新街口核心商圈，2.5 小时短时带宠友好消费路线。

示例输入：

```text
我现在在南京新街口，想带一只中型犬出门 2.5 小时，不想去太挤的地方，能短暂散步，再找个宠物友好咖啡坐一会儿，预算 100 元以内。
```

## 我的工作

- 设计 POI 采集与清洗流程。
- 使用百度地图 Place API 采集南京新街口周边 POI。
- 设计宠物友好判断、可信度、风险提示和路线角色规则。
- 将 raw POI 转换为 shortlist CSV。
- 将 shortlist CSV 转换成前端可用的结构化 JSON。
- 实现 Streamlit MVP 验证页。
- 整合 Stitch 风格静态前端，支持路线展示和多轮调整场景。
- 实现 FastAPI 后端，提供路线规划 API、健康检查、LLM-ready 接入和规则兜底。
- 扩展出行可行性评分、风险雷达、路线对比、社区反馈和代溜服务模块。

## 商业价值

- 将“带宠出行”从单点搜索升级为组合式本地生活消费路线。
- 路线中可连接咖啡、餐饮、洗护、用品补给等美团交易入口。
- 用户反馈可反哺宠物友好标签，沉淀高质量本地生活数据资产。

## 后续可扩展方向

- 接入真实 LLM 后端，完成自然语言理解和路线解释生成。
- 当前 FastAPI 后端已经预留 OpenAI-compatible LLM 接口，可配置 API Key 后启用。
- 接入地图 SDK，展示路线空间关系。
- 引入商家侧宠物友好验证机制。
- 扩展到更多城市和更多宠物出行场景。
