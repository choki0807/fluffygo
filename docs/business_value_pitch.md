# FluffyGo 商业价值路演文案

## 建议放置位置

这部分不建议放在 C 端 Demo 主界面中。它更适合放在路演 PPT、项目介绍页或答辩讲稿中，用于解释为什么 FluffyGo 对美团本地生活有价值。

## 一页 PPT 标题

FluffyGo：把带宠出行从单点搜索升级为组合式本地生活消费路线

## 核心论点

城市养宠用户的真实需求不是“找一家宠物店”，而是完成一次可执行的出行：从当前位置出发，判断哪里能散步、哪里能停留、哪里能消费、哪里能补给，以及哪些地方存在携宠风险。

FluffyGo 将这些碎片化需求组织成路线，让宠物友好标签、商户交易入口和用户反馈形成闭环。

## 对美团的价值

1. 拓展本地生活消费场景

带宠出行天然连接咖啡、轻食、餐饮、宠物洗护、宠物用品、代溜服务等多类交易入口。FluffyGo 不是替代单点搜索，而是把多个本地生活供给串联成一次出行决策。

2. 提升宠物频道的使用频次

传统宠物频道更偏服务搜索，用户只有洗护、医疗、用品等明确需求时才会打开。FluffyGo 将“日常遛狗、周末短逛、雨天备选、顺路补给”纳入产品入口，有机会提升低决策成本、高频次的打开场景。

3. 沉淀宠物友好标签资产

宠物友好不是单一标签，而是由空间类型、犬型限制、外摆状态、室内准入、人流压力、用户反馈共同构成的动态标签。路线使用和到店反馈可以反哺商户画像，形成更高质量的本地生活数据资产。

4. 增强交易转化路径

用户在路线中看到的不只是 POI 名称，而是明确动作：电话确认、查看团购、预约洗护、加入路线、发布代溜需求。相比单点列表，路线场景更容易承接连续消费和即时决策。

## 路演讲法

可以这样讲：

FluffyGo 的价值不在于又做了一个“宠物友好地图”，而是把用户原本分散在地图、点评、宠物频道和社交平台里的决策，整合成一条可执行路线。

对用户来说，它解决的是“我现在能带狗去哪”的问题。

对平台来说，它把一次带宠出门拆成多个可交易节点，并通过用户反馈持续更新宠物友好标签。

这让美团宠物频道从低频服务搜索，延伸到更高频的日常带宠本地生活入口。

## PPT 页面建议

- 页面 1：用户痛点
  - 带宠出门不是找一个点，而是判断一整段路线是否可行。
  - 用户需要同时考虑距离、拥挤、犬型限制、外摆状态和消费预算。

- 页面 2：产品方案
  - 一句话输入。
  - 地图周边目的地。
  - 多路线对比。
  - 宠物友好证据体系。
  - 交易动作入口。

- 页面 3：商业价值
  - 消费链路：咖啡、餐饮、洗护、用品、代溜。
  - 数据资产：动态宠物友好标签。
  - 平台增量：从宠物服务频道扩展到带宠本地生活入口。
