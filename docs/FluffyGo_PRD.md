# FluffyGo PRD

## 1. 产品定位

FluffyGo 是一个 AI 本地路线智能规划产品，面向城市养宠用户的短时带宠出行场景。用户通过一句话输入当前位置、宠物类型、可用时间、预算和偏好后，系统生成可执行、可比较、可交易、可反馈的带宠本地生活路线。

参赛赛道：现在就出发：AI 本地路线智能规划。

## 2. 目标用户

- 城市养狗用户，尤其是中小型犬和中型犬主人。
- 周末或下班后想短时出门，但担心商圈拥挤、携宠限制和目的地不确定的用户。
- 需要在散步、咖啡/轻食、洗护、用品补给、雨天备选之间快速做决策的用户。
- 不方便亲自出门时，希望将路线转为代溜服务的用户。

## 3. 核心用户痛点

1. 带宠出门不是单点搜索，而是一条路线决策。
2. 宠物友好信息分散在地图、点评、社交平台和商户咨询中。
3. 核心商圈存在人流、室内准入、犬型限制、天气、噪声等不确定风险。
4. 用户很难判断某个目的地是否真的适合当前宠物和当前时间。
5. 平台侧缺少动态、细颗粒度、可反哺推荐的宠物友好标签资产。

## 4. 核心使用场景

### 4.1 短时散步 + 友好消费

用户输入：我现在在南京新街口，带一只中型犬出门 2.5 小时，不想太挤，想短暂散步，再找个宠物友好咖啡，预算 100 元以内。

系统输出：开放空间 + 友好消费点 + 可选补给点路线。

### 4.2 只想去公园，不想消费

用户输入：我只想带狗去公园散步，不想去咖啡店。

系统输出：纯散步路线，不出现咖啡消费点。

### 4.3 预算很低

用户输入：预算只有 30 元。

系统输出：免费/低消费路线，优先开放空间，减少洗护和高客单消费点。

### 4.4 下雨备选

用户输入：如果下雨怎么办？

系统输出：雨天备选路线，明确哪些点只是备选，需要二次确认。

### 4.5 顺路洗护/补给

用户输入：想顺路洗护或者买点宠物用品。

系统输出：服务/补给线，出现预约洗护、用品补给等交易动作。

## 5. 产品模块

### 5.1 首页

- 以当前位置为中心展示附近宠物友好目的地。
- 支持区域切换：新街口、鼓楼、秦淮、玄武。
- 提供一句话输入和快速规划入口。
- 展示周边目的地、社区反馈和常用场景入口。

### 5.2 路线规划页

- 展示 AI 解析结果：地点、时间、宠物、预算、偏好、避免项、消费意图。
- 展示推荐路线：路线名称、预算、时间、可行性评分、风险摘要。
- 展示路线站点：站点角色、地址、距离、空间类型、风险提示、交易动作。
- 接入百度地图步行路线，按起点、途经点、终点展示。

### 5.3 路线对比

- 支持主路线、低压力、省钱、雨天、纯散步、服务补给等候选路线。
- 展示预算、距离、可行性、适配度和交易点数量。
- 点击候选卡片切换当前地图路线。

### 5.4 风险与证据体系

- 出行可行性评分。
- 风险雷达：拥挤、准入、犬型适配、天气、规则不确定性、宠物压力。
- 宠物友好标签依据：空间类型、证据来源、核验问题、用户反馈。
- 不直接把“可信度”作为炫耀点，而是通过按钮展开解释。

### 5.5 社区与反馈

- C 端用户分享路线情报、拥挤状态、外摆开放、犬型限制等。
- 用户反馈可反哺 POI 标签和后续推荐排序。
- 代溜服务作为商业化延展：可将当前路线转为认证代溜员履约方案。

### 5.6 个人记录

- 我的路线收藏。
- 到店确认记录。
- 路线核验贡献。
- 宠物出行档案。

## 6. 推荐逻辑要求

系统需要根据用户输入动态改变推荐结果：

- 明确排除咖啡时，不应推荐咖啡线。
- 预算降低时，应减少消费点和高客单服务。
- 下雨时，应优先雨天备选/半室内/用品店等点位。
- 需要洗护时，应增加服务/补给点和预约动作。
- 有负反馈的 POI 应降权或退出主推荐。
- 起点应来自用户输入位置，路线连接起点、途经点和终点。

## 7. 数据与接口

### 7.1 数据来源

- 百度地图 Place API 采集 POI。
- 本地 CSV/JSON 清洗为 Demo 数据。
- 运行时可调用后端实时 POI 接口。

### 7.2 后端接口

- `GET /api/health`：健康检查。
- `GET /api/demo-data`：读取 Demo 数据。
- `GET /api/live-pois`：按区域和关键词获取 POI。
- `POST /api/plan-route`：根据用户输入生成路线。
- `POST /api/poi-feedback`：提交 POI 到店反馈。
- `GET /api/demo-readiness`：提交前完整度检查。

## 8. 技术约束

- 前端不得暴露服务端 LLM API Key。
- `.env` 只用于本地协作，不应公开提交。
- Demo 不爬取美团或大众点评。
- 后端不可用时，前端应有本地兜底，不应白屏。
- 地图 AK 上线时需要配置正确 Referer 白名单。
